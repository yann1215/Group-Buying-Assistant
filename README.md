# 无盈利拼团小助手 Group-Buying-Assistant


这是一个用于金属徽章无盈利拼团的程序，目的是帮助车主核对成员、计算均摊、计算大货。

## 使用说明

### 数据库解密

**key**：微信数据库解密密钥，用于解析聊天记录。

如果使用 4.0.3.19 及以下的 4.x 版本微信，程序支持自动解密；如果无法安装低版本微信，可以安装 4.1.0.30 版本的微信，然后借助 wx_key.exe 获取微信数据库解密密钥（不需要图片解密密钥）。

key 会本地缓存，解密的数据库信息也缓存在本地。输入一次key之后，同一账号在同一设备上，（在wx大版本更新前，应该）不需要再次输入 key。但是更换账号或者更换设备后，需要重新获取 key 并输入。

本程序只会在你的授权下访问你自己的微信本地数据库，不会把你的数据上传至互联网。如果有对数据泄露或封号的担忧，请勿使用本程序。使用前请务必知悉。



### 待处理信息上传

> 输入示例：群聊 相亲相爱一家人，订单 share.xlsx

1️⃣**群聊**：输入车群名称。建议输得尽量准确。

**2️⃣订单**：用于查群成员昵称是否备注正确、以及计算均摊的订单。

目前，需要把自助拼单的订单文件上传至程序根目录的 orders 文件夹内（建议重命名为简单的名称）。如果没有文件夹，就自行新建文件夹。

**3️⃣大货订单**：用于查大货的订单。相关功能可以使用，但是还在开发更新中，后续可能调整。

### 特殊成员名单输入

> 输入示例 1：车主 xxx，单号 7，参摊
>
> 输入示例 2：画师 xxx

特殊成员名单支持：

| 特殊成员 | 人数限制        | 是否必须设置 |
| -------- | --------------- | ------------ |
| 车主     | 必须且只能 1 人 | **必须**     |
| 画师     | 最多 1 人       | 可选         |
| 章稿画师 | 最多 1 人       | 可选         |
| 供稿人   | 最多 1 人       | 可选         |
| 工具人   | 可以有多人      | 可选         |

特殊成员默认不参摊，如果参摊需要额外备注。



### 操作指令

> 输入示例：查成员

1️⃣**“查成员”**：检查群昵称和订单是否匹配。

> 输入示例：查均摊，个数摊，金额1000

2️⃣**“算均摊”**：支持人头摊、个数摊，多款商品时支持独立均摊计算与拉通均摊计算（默认拉通）。

**均摊计算会排除不参摊的特殊成员的订单（例如车主默认不参摊）。**在计算个数摊时，“摊画师”“摊金主”开头的商品和“专拍”结尾等**特殊商品会排除在外**（请不要给不参摊的商品起太复杂的名字，会无法被识别出来）。

计算个数摊时，底胚默认不参摊，特典默认参摊。**计算前会检查订单，是否有人只拍了底胚、没有入本体。**（但是有多款商品、要求拥有对应本体的情况暂时无法识别，功能开发中。）

> 输入示例：算大货

**3️⃣“算大货”**：计算大货。计算的过程其实就是导出自助拼单表格的总金额。

计算大货之前，会提示车主检查单价变动、商品价格同步、均摊抵扣大货等情况，确认之后才会继续大货计算。
