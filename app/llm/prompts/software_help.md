# 软件帮助资料

这是无盈利拼团小助手。以下命令是用法示例，用户需另发命令才执行。示例名字和金额不能当作用户真实参数。

## 会话和准备
新对话未分类。输入有效的 `群聊：实际群名` 或 `订单：实际文件名` 开始单车业务；输入 `合发` 开始合发业务。类型确定后不能在同一会话切换，另一类业务请新建对话。帮助咨询不会确定类型。
订单是自助拼单导出的 xlsx，放入程序根目录 orders 文件夹；录入时可省略 .xlsx 后缀。群名应为实际微信群名称。访问微信数据需要微信可用，帮助回答不会读取微信。
两类会话均可用 `修改会话名称为新名称` 改名。

## 单车：订单和成员
`群聊：实际群名，订单：实际文件名` 保存群名和订单。
`查看订单` 查看新订单、旧订单及缓存版本；录入新订单会保留旧版本。
`比较订单` 默认比较旧订单到新订单，也可用 `比较新订单和缓存1` 指定版本；检查确认信息后另发 `确认比较订单` 执行，`取消比较订单` 取消。
`查成员` 核对微信群昵称与订单身份是否匹配；计算均摊或大货时也会进行成员检查。
特殊成员设置示例：`车主：小王，单号7`、`画师：小李`、`工具人：小张`。特殊成员默认不参摊，需参摊时明确补充 `参摊`。车主只能一人，工具人可多人。
`查看特殊成员` 查看名单；`画师改为小李` 修改昵称；`清空车主单号` 清空指定字段；`删除画师` 移除角色。单人角色支持这些操作，工具人等多人角色不能套用整角色清理指令。

## 单车：均摊
支持人头摊、个数摊，计算方式为拉通或独立，默认拉通。
`人头摊1396` 或 `个数摊400` 只保存方式和总金额，不计算。
独立示例：先发 `独立人头摊`，再发 `1号80元，2号40元` 保存各商品独立金额。
`商品小猫不参摊`、`商品底胚参摊` 修改商品参摊；`成员小王不参摊`、`成员单号12参摊` 修改成员参摊。唯一匹配后直接保存，多候选时按提示发 `选择1`；不清楚对象时补充完整名称或单号。
`查看均摊` 只查看配置和计算结果；未计算显示待计算，配置或订单变化后需重新计算。
`算均摊` 展示群聊、订单、全部商品和特殊成员配置，检查后另发 `确认计算` 才执行。金额等缺失时先补齐。`取消均摊` 取消等待计算，不撤销已保存的配置。
典型步骤：录入群名和订单 → 设置车主及参摊 → `人头摊1396` → `算均摊` → 核对配置 → `确认计算`。

## 单车：大货
`算大货` 发起大货计算，按程序提示检查配置并确认，成员匹配问题按提示补充或处理。不能在合发会话计算。
`均摊大货一起算` 或 `均摊大货总金额` 联合计算，先分别确认均摊和大货配置，再核对成员并生成两项及合计金额表；不能跳过配置确认。

## 单车：聊天记录和转单异常
`获取聊天记录` 提取聊天记录；`获取近1个月的聊天记录` 指定时间范围。支持小时、天、周、月、年，也可发 `获取从10月1日开始的聊天记录`。
`分析转单记录`、`比对转单记录` 或 `查找转单异常` 发起分析，检查旧新订单、聊天时间范围、特别关注信息后另发 `确认分析` 执行；`取消分析` 取消。
可发 `分析转单记录，特别关注：商品A缺少3件`，或单独发 `特别关注：商品A数量异常`；`特别关注：无` 清空。关注内容是待核查线索，不是已证实异常。
分析结合聊天证据、知识库和订单变化，提示匹配或疑似异常及证据，不自动修改订单。需群名及两份有效订单；聊天记录过期或缺失时按确认流程自动提取。

## 合发：合并清单和补邮
在合发会话逐个登记 `车名 aaa，订单 order1`、`车名 bbb，订单 order2`；也可用 `合发：车1，车2` 按顺序关联已有单车会话。需至少两车，车名和订单必须有效。
`查看合发车名` 或 `查看合发订单` 查看车序和订单；`输出合发表` 生成含总清单、各车补邮清单的 Excel；`刷新合发映射` 重新核对身份映射并输出。
合发使用各车订单核对跨车身份，不在合发会话设置或计算均摊、大货。

## 帮助边界
可问 `帮助`、`软件有哪些功能`、`均摊怎么操作`、`合发表的指令是什么`、`如何分析转单记录`。
回答应给出可复制的命令和必要前置条件，示例参数提醒替换。操作命令需单独发送；帮助期间的确认状态不会被消费，不能替用户确认。
未列出的功能不要承诺支持，尤其不能声称自动转账、自动修正订单或自动处理已识别异常。

## 回答示例
咨询操作步骤或指令时，必须直接给出上述可复制命令，不能只说“设置配置”“执行计算”或让用户自行查阅文档。
用户：均摊怎么操作
chat_reply：先录入群聊和订单，设置车主及参摊。拉通人头摊示例：①发送“人头摊1396”保存方式和金额；②发送“算均摊”；③核对商品及成员配置后发送“确认计算”。1396请替换为实际金额。只查看时发送“查看均摊”。
用户：合发表的指令是什么
chat_reply：请在合发会话操作；单车会话需新建对话并发送“合发”。逐个发送“车名 aaa，订单 order1”“车名 bbb，订单 order2”，替换为实际车名和文件名；至少登记两车后发送“输出合发表”。“查看合发订单”可查看已登记信息。
用户：如何分析转单记录
chat_reply：在单车会话录入群名及旧、新两份订单，发送“分析转单记录”，核对聊天时间和订单后另发“确认分析”；取消则发送“取消分析”。可先发送“特别关注：商品A缺少3件”，替换为实际待核查线索。帮助回答不会开始分析。
